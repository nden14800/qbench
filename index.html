Detailed methodology, external-source notes and benchmark caveats
Method: QBench Composite Index 3.5 is an independent six-domain percentile index, not AA's native Intelligence Index. It includes each AA v5 core component that clears the public-data threshold, eligible AA standalone evaluations (AA-3D, Harvey LAB-AA, AA-AnalystAgent, APEX-Agents-AA, EnterpriseOps-Gym-AA, MLCR-AA and Code2Video-AA), and traceable external frontier benchmarks (ARC-AGI-2, FrontierMath Tiers 1–3 v2, LiveBench 2.0, OSWorld 2.0 and SWE-Bench Pro). Each benchmark is normalized to a midrank percentile using the best reported configuration per exact model name. Benchmarks have one primary domain and equal weight within that domain; six domain averages are then equally weighted. An evaluation needs at least eight unique models. A model is ranked only with at least four eligible evaluations across at least three of six domains. Missing scores are never imputed. The score is a broad comparative index, not an official AA score, and some public leaderboards use different harnesses from AA's internal runs.
Frontier extensions: FrontierMath Tier 4 v2 is tracked separately because the published top score reaches 100%. SWE-Bench Pro V2 Full is tracked separately because its official top score reaches 99.40%; the variant-unclear third-party snapshot is kept distinct from the official Full tab. METR Time Horizons is retained as a historical reference because METR says its public board is no longer actively updated. The directory includes every evaluation listed in the current AA evaluation catalogue, including standalone and legacy entries.
AA Index v5 announcement · Official weights and methodology · MirrorCode · FrontierMath Erdős
External benchmark provenance: AA v5 components are included only as individual benchmark datasets when their public model coverage clears QBench’s threshold. AA’s official category weights are not used. QBench applies its own six-domain equal-weight aggregation described above.

Public-source comparability: Terminal-Bench 4.0 and HLE-Diamond are imported from their public leaderboards, not AA’s private run pipeline. Their benchmark identity matches the AA v5 components, but their harnesses/scoring settings are not guaranteed to match AA’s internal runs.Source caveat: public leaderboard scores can use different harnesses from AA’s internal Stirrup runs. In particular, Terminal-Bench-Science uses Vals AI / Mini-SWE-agent single-run results, while AA reports its own three-run Stirrup evaluation. These are same benchmark versions, not identical evaluation runs.
Additional hard benchmarks: FrontierMath Tier 4 v2 remains a useful standalone test (41 private problems; current best 100%), but is not an unsolved benchmark. FrontierMath Erdős and MirrorCode are better current frontier monitors; ARC-AGI-3 is tracked separately because public results are team/system submissions rather than base-model scores.

How to read QBench

評価結果の意味と比較条件を明確にするための基本ルール。

01 / BENCHMARK

One ranking per test

評価ごとに目的・問題形式・スコア単位が異なるため、基本はベンチマーク単位で順位を比較します。

02 / SCORE

Keep the published scale

正答率、Elo、成功率など、元の評価が公表する単位をそのまま表示。異なる単位を無理に足し合わせません。

03 / COVERAGE

Show the available evidence

モデル数・設定数・データ更新日・出典を明示。未公開の結果や不足値を推測で補完しません。
