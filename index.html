Methodology & evidence policy

AA v5の方式を基準にしつつ、独立した追加ベンチマークは別枠で分析。

AUDITABLE / NO IMPUTATION
01 / AA V5

Same nine evaluations

AA-Briefcase v1.1、AutomationBench-AA、GDP.pdf、Terminal-Bench 4.0、FrontierCode 2.0、Terminal-Bench-Science 0.1、CritPt v2 Hard Subset、AA-Omniscience v1.1、HLE-Diamondを同じ評価セットとして登録。

02 / WEIGHTS

Four categories · 25% each

Knowledge Work、Coding、Science、Generalを各25%。領域内の評価ウェイトもAA v5公式配分に合わせる。追加ベンチマークはAAスコアに混ぜない。

03 / NO IMPUTATION

Complete coverage required

同じモデル設定で9評価すべてのスコアが揃うまで、QBench独自のAA互換総合点は計算しない。欠損値の推定、モデル名だけの強引な別名統合は禁止。

04 / PRIVATE TESTS

Public evidence is not a rerun

AA v5の一部は非公開テスト。AAが公表したリーダー要約と第三者の公開リーダーボードを区別し、非公開問題を再現したとは主張しない。

05 / CONFIGURATION

Model ≠ configuration

モデル名、reasoning effort、実行ハーネスを分離。ベースモデル数、モデル設定数、結果行数を別々に数え、同じモデルのMax/High/Lowを一つに潰さない。

06 / EXTENSIONS

Hard, unsaturated benchmarks

Epoch AIの95ベンチマーク・418モデルの公開データベースを探索母集団にし、FrontierMath、ARC-AGI-2、Mystery Game Puzzles、SpireClimbなどを追加。飽和済み評価は難度・更新日を注記して別扱い。

注意: AA v5の60%は非公開テストセットまたは保留回答を使う評価に基づく。QBenchは公開された結果の収集・比較を行うもので、AA独自の非公開実行環境を完全に再現するものではない。結果の単位・ハーネス・試行回数・信頼区間は出典に従って保持する。
