Methodology & data policy

What the composite means — and what it does not mean.

TRANSPARENT / REPRODUCIBLE
01 / COHORT

Exact model identity

Only models present under the exact same model name in all five families enter the composite. No model aliases are inferred and no missing results are imputed.

02 / WEIGHTS

Equal family weighting

LiveBench 2.0, GPQA Diamond, FrontierMath, ProofBench and Furniture Assembly each contribute 20%. FrontierMath's two tiers are averaged first and count as one family.

03 / SOURCE SCALE

Published values retained

Source-reported 0–100 scores are retained as published. This is a descriptive composite, not a calibrated universal intelligence scale.

04 / SEPARATE DATA

Specialist results stay separate

SWE-bench Pro V2 and SWE-bench Verified are shown independently because their model coverage does not match the exact-match composite cohort.

05 / AA EXCLUSION

No AA Index v5 inputs

None of the nine evaluations used by Artificial Analysis Intelligence Index v5 is included in this composite. QBench does not reproduce AA's scores, weighting or index.

06 / INTERPRETATION

Small gaps need context

Benchmarks differ in task design, difficulty, tool access, reasoning effort and harness. A small composite gap should not be read as a definitive model ranking for every use case.

Important: QBench's composite is an independent aggregation of public third-party benchmark snapshots. It is not a QBench-run evaluation, not an official ranking, and not a substitute for inspecting each benchmark's native result and methodology. Snapshot dates are shown beside every source.
