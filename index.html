How QBench Index 1.0 works
Each benchmark score becomes a percentile within that benchmark's own model cohort. Evaluation percentiles are averaged inside each domain; available domain scores are then averaged equally. With all four domains present, each contributes 25%. With incomplete coverage, only observed domains are averaged and the result is labelled provisional.
Formal rank: 4+ eligible evaluations across 3+ domains · Provisional: 2+ evaluations, but not enough rank coverage · Single result: shown in Models without a composite score.
